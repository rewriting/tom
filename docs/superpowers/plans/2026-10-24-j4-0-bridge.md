# J4.0 — pont Java → Go : binaires, corrections gomgo, préfixe par fichier, `--goFrom`, identité — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** préparer le portage « de la fin vers le début » du compilateur
Tom en Tom+Go : binaires Go installés dans la dist, deux défauts de gomgo
corrigés, plusieurs `.t` par paquetage Go (préfixe par fichier), pont
Java → Go (`--goFrom`, paquet texte, `tomgo suffix`) et preuve que le
paquet et tous les dumps `--intermediate` se relisent à l'identique côté
Go (P0).

**Architecture:** le compilateur Tom+Java (`src/tom/`, dist `src/dist`)
gagne une sortie vers un processus Go : avant le plugin nommé par
`--goFrom`, la plateforme (`PluginPlatform`) passe la main à
`tom.engine.bridge.GoBridgePlugin`, qui écrit un paquet texte (une donnée
par ligne, termes Gom par `toString()`) sur l'entrée standard de
`<dist>/bin/tomgo suffix`. Côté Go (module `tom`, `src/go/tom`), le
paquetage `tom/engine/bridge` lit et réécrit ce paquet avec l'ADT du
moteur (`tom/engine/adt`, généré par gomgo). En J4.0, `tomgo suffix` ne
connaît aucune phase (il les refuse) ; `--goCheck` vérifie l'aller-retour
puis laisse la chaîne Java finir.

**Tech Stack:** Tom+Java (`.t`), Ant via `./build.sh`, JDK 8 pour
construire, Go 1.26+ (1.27 installé), `mage` (`mage -d magefiles -w .
<cible>`).

Spec : `docs/superpowers/specs/2026-10-24-j4-tom-go-compiler-design.md`
(§4.1 pont, §4.2 paquet, §4.3 binaires et préfixe, §5 tests, §6 jalons
J4.0a–J4.0d, §8 décisions D1–D6).

## Global Constraints

- **Décisions (spec §8)** : D1 (b) préfixe `tom_<F>_` sur toutes les
  déclarations de niveau paquetage générées pour Go, appliqué au
  `GoGenerator` Java, sans option ; D2 commande `tomgo` (sous-commande
  `suffix`), sources `src/go/tom/engine/cmd/tomgo`, binaires `gomgo` et
  `tomgo` **installés dans `<dist>/bin`** par la construction, trouvés
  depuis `tom.home`, `TOMGO_BIN`/`GOMGO_BIN` seulement en surcharge ;
  D3 crochet générique `--goFrom <plugin>` dans `PluginPlatform` ; D4
  `src/dist` compile le Tom+Go (garde `CheckFresh`) ; D5 (a) le côté Go

  `-go`) ; D6 paquet texte, un terme par ligne, stdin/stdout.

```go
// goCommands are the Go commands of module tom installed in <dist>/bin
// (the dist ships binaries; src/ holds sources only). A command whose
// main package is absent from the tree is skipped (tomgo before J4.0c
// in the amorce).
var goCommands = []struct{ name, pkg string }{
	{"gomgo", "./gom/cmd/gomgo"},
	{"tomgo", "./engine/cmd/tomgo"},
}

// InstallGo builds the Go commands into binDir: from = "src" builds them
// from src/go/tom (after bootstrap: the ADTs are generated locally),
// from = "stable" from the amorce stable/go/tom (GOWORK=off). Called by
// build.xml (src.dist, stable.dist).
func InstallGo(from, binDir string) error {
	var dir string
	var env []string
	switch from {
	case "src":
		mg.Deps(Bootstrap)
		dir = tomDir
	case "stable":
		dir, env = stableGoDir, []string{"GOWORK=off"}
	default:
		return fmt.Errorf("installGo: from must be src or stable, not %q", from)
	}
	abs, err := filepath.Abs(binDir)
	if err != nil {
		return err
	}
	if err := os.MkdirAll(abs, 0o755); err != nil {
		return err
	}
	for _, c := range goCommands {
		if _, err := os.Stat(filepath.Join(dir, filepath.FromSlash(c.pkg))); err != nil {
			fmt.Printf("installGo: %s: no %s in %s, not installed\n", c.name, c.pkg, dir)
			continue
		}
		if err := runInEnv(dir, env, "go", "build", "-o", filepath.Join(abs, c.name), c.pkg); err != nil {
			return fmt.Errorf("installGo: building %s from %s: %w", c.name, dir, err)
		}
		fmt.Printf("installGo: %s -> %s\n", c.name, filepath.Join(abs, c.name))
	}
	return nil
}
```

Constat (spec §3.2) : `AndConstraint` est AU d'unité `TrueConstraint()` ; son hook absorbe l'unité, donc `MakeAndConstraint(x, y)` est `ConsAndConstraint(x, y)` dont la queue `y` est un élément. `ToATerm` exige une queue liste et panique (« ClassCastException: the ATerm of FalseConstraint() is not an ATermList ») ; Java a le même transtypage (`src/gen/tom/engine/adt/tomconstraint/types/constraint/AndConstraint.java:130`). La correction est une extension voulue.

- [ ] **Step 1 : tests qui échouent**

`test/go/adt/aterm_test.go` :

```go
package adt_test

import (
	"testing"

	adt "tom/engine/adt"
	"tom/library/aterm"
)

// An AU list whose unit is absorbed ends with an element (Cons(x, y)):
// its ATerm is the list of all the elements, and converts back to the
// same term (Java's toATerm throws ClassCastException here: deliberate
// extension, doc/go/README.md).
func TestToATerm_AUListEndingWithElement(t *testing.T) {
	x := adt.MakeNegate(adt.MakeTrueConstraint())
	y := adt.MakeFalseConstraint()
	for _, c := range []adt.Constraint{
		adt.MakeAndConstraint(x, y),
		adt.MakeAndConstraint(x, y, x),
		adt.MakeOrConstraint(x, adt.MakeTrueConstraint()),
	} {
		l, ok := c.ToATerm().(*aterm.ATermList)
		if !ok {
```

```go
// over to the Go suffix (spec J4 §4.2): one datum per line, Gom terms by
// their String().
package bridge

const Version = 1

type Option struct {
	Name  string
	Kind  string // "bool", "int" or "string"
	Value string // decoded value (strconv.Unquote for "string")
}

type Bundle struct {
	From    string         // plugin name, without spaces ("Backend")
	Input   string         // absolute path of the .t
	Output  string         // absolute path of the generated file
	Options []Option       // sorted by name
	Used    []adt.KeyEntry // sorted by String()
	Types   []adt.TomType  // in the order of the Java map keys
	Table   adt.TomSymbolTable
	Code    adt.Code

// unknown version or a missing "end" is an error naming the line number.
func Read(r io.Reader) (*Bundle, error)

// Write writes b in the format Read reads; Write(Read(x)) == x byte for
// byte for every bundle written by GoBridgePlugin.
func (b *Bundle) Write(w io.Writer) error

// Option returns the decoded value of an option and whether it exists.
func (b *Bundle) Option(name string) (string, bool)
```
